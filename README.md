# 东莞市喜艺服饰有限公司官网新版交付说明

## 1. 参考站架构拆解

本次只借鉴成熟服装工厂站的版式和模块逻辑，不使用对方图片、品牌、Logo 和原文案。

参考站可复用的框架逻辑：

- 顶部提示栏：一句工厂定位或欢迎语，右侧放语言切换。
- 品牌导航区：左侧 Logo，中间主导航，右侧搜索和联系方式。
- 多级导航：Products、How To Start、Production、Services、Support、About、Contact。
- 产品下拉：主分类直接下拉到具体品类。
- 首页首屏：大幅工厂或产品生产图作为背景，左侧放核心定位、按钮和数据。
- 产品分类专区：首页只放核心分类入口；完整产品内容放到独立产品页。
- 产品总页：左侧分类栏，右侧产品卡片，保留网格/列表切换的视觉位置。
- 产品详情页：左侧分类/联系方式，右侧大图、款式图库、参数表、询价按钮。
- 成衣案例区：用多列图文卡片展示可替换的项目案例。
- 工厂实力区：厂房、打样、生产流程、质检、包装按流程展示。
- 服务区：按不同客户或不同合作方式拆分模块。
- 支持区：保留 FAQ、定制科普、询价清单，删除不适合首版的账号类入口。
- 信任栏目：质量控制声明、社会责任、公司动态、工厂故事、工厂参观/图片、样衣开发、尺码版型指南、印花服务、工厂视频。
- 页脚：大 CTA、公司简介、产品分类、工厂能力和联系方式四栏排布。
- 悬浮咨询：右下角桌面纵向按钮，手机端固定底部按钮。
- 弹窗样式：小型询价提醒弹窗，支持关闭，不做强制表单。
- 页面动效：滚动进入时轻微上移动画，不做复杂特效影响加载。

## 4. 页面布局说明

- 颜色：黑白灰为主，青绿色作为行动按钮和重点色，少量铜色可后续用于高端细节；不使用参考站原有的深蓝单品风格。
- 首页：首屏大图使用棒球服生产参考图，表达“工厂实拍定制服务”方向。
- 产品：首页做入口，产品页做完整分类，详情页承载大量款式，适合后续每个产品增加很多图片。
- 工艺：工艺卡片可以直接跳到工艺页锚点，后续可替换为你们实际做过的工艺图。
- 案例：先用安全占位表达“案例位置”，不写未确认客户名和虚假订单数据。
- 联系：电话、WhatsApp、微信、邮箱、地址都已放入页脚和联系页。
